# अनुभव (ANUBHAV)

> *"Learn from experiences. Share your journey. Inspire the next generation."*

## 📖 About the Project

College is much more than lectures and examinations. Every student experiences internships, hackathons, placements, failures, achievements, friendships, and countless memorable moments.

However, these experiences are often lost after graduation.

**ANUBHAV** aims to preserve these stories by creating a platform where seniors can document their journeys so that juniors can learn, gain inspiration, and avoid common mistakes.

---

## ✨ Features

- 🔐 Simple Login Page
- 🏠 Interactive Home Page
- 📚 Timeline of Senior Experiences
- 📖 Dedicated Blog Page for Every Experience
- ✍️ Write & Share Experience Page
- 🎨 Modern Pink & White Responsive UI
- 📱 Mobile-Friendly Layout
- 🖼️ Personalized Images for Every Story
